# Jorge Gato — Online Resume

A static HTML/CSS resume site.

Live site: https://jorge-gato.github.io/Online-Resume/

## Structure

- `index.html` — the page
- `style/style.css` — the layout and styling
- `images/` — certification logos and the favicon
